# Bitácora de uso de IA

## 1. Herramientas utilizadas
ChatGPT/Codex (asistente de programación; versión exacta no informada).

## 2. Propósito
Localizar el portafolio E2, migrar HTML/CSS a React, separar componentes, diseñar tipos, integrar API de GitHub y preparar documentación.

## 3. Prompts representativos
- "hay que hacerlo con mi portafolio de frontend que hice el primero"
- "gestionar los tres estado cargando error ... codigo 200 el 404"
- "uso de la ia el inventario.md lo que tenia antes git pull aplicar accesibilidad"
- "ya hazlo entonces"

## 4. Output recibido
Estructura React/TypeScript, componentes, rutas, hook de API, manejo HTTP, contexto de tema, formulario, estilos migrados y borradores de documentación. La IA realizó la migración inicial.

## 5. Ajustes y verificación
La IA adaptó clases y recursos del HTML original. Las pruebas del estudiante y sus correcciones personales deben añadirse aquí tras realizarlas. No se afirma que se hayan realizado pruebas que aún no tienen evidencia.

## 6. Reflexión crítica final
Pendiente de completar personalmente por la estudiante tras revisar y explicar los componentes, estados, rutas y API. La IA puede acelerar el desarrollo, pero delegar la implementación sin comprenderla genera deuda cognitiva; es necesario poder justificar el código y reproducir las verificaciones.
